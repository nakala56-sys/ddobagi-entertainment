# 이미지 출처

새 페이지의 WebP 이미지는 사용자가 제공한 「또바기 회사소개서.pdf」에서 로컬로 추출했습니다.

| 경로 | 소개서 페이지 | 사용 범위 |
| --- | --- | --- |
| home/hero.webp | 11 | 스튜디오·방송 사례 |
| home/studio.webp | 10 | 실제 방송 공간 |
| home/creator-stories.webp | 9 | 소속 크리에이터 방송 사례 |
| about/brand.webp, services/setup.webp | 3 | 장비 설치·세팅 사례 |
| services/remote.webp | 4 | 원격 기술지원 설명 이미지 |
| services/directing.webp | 5 | 디렉팅 설명 이미지 |
| services/design.webp | 6 | 디자인 제작 설명 이미지 |
| services/events.webp | 7 | 이벤트 기획 설명 이미지 |
| benefits/beauty.webp | 8 | 제휴 뷰티 지원 설명 이미지 |
| equipment/camera.webp, lighting.webp, audio.webp, pc.webp, streaming.webp | 3 | 방송 환경 사진의 일부 |
| equipment/studio.webp | 11 | 스튜디오·방송 사례 |
| about/location.svg | 자체 SVG | 주소 안내 그래픽, 실제 도로 약도 아님 |

장비 카테고리는 제품 모델이나 사양을 보증하지 않습니다. PDF의 설명용 이미지와 실제 활동·스튜디오 이미지를 구분해 사용했습니다. 추출 이미지 해상도는 PDF 원본에 제한됩니다. 원본 사진 확보 시 같은 경로에 교체하면 됩니다.
